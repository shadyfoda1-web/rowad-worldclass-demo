# Rowad Al Asema — World-Class Animated Prototype

Single-page bilingual corporate website prototype.

## Included
- Arabic / English toggle
- Cinematic hero
- Scroll reveal animations
- 3D hover/tilt effect
- Animated counters
- Marquee ticker
- Office & warehouse showcase
- WhatsApp CTA
- Google Maps embed
- Responsive mobile design

## Deploy
Upload `index.html` and the `assets` folder to the GitHub repository, then Vercel will deploy automatically.
